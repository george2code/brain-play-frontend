# Flag Master catalog

`flags.json` contains 195 country records: 193 UN member states plus the Holy See and Palestine. Each record has an ISO 3166-1 alpha-2 code, country names in English, Russian and Ukrainian, two localized facts about the flag, and a source URL. The first fact appears before the answer; the second expands on it after the answer. The JSON is bundled with the frontend so translations never require a runtime translation service.

The first fact is primarily a short story from the flag's history: a contest, an earlier use, a change of regime, or an unusual rule. Facts focused on an adoption year or a visual description are deliberately sparse (each under 10% of the catalog). The second fact supplies the names, dates or context after the player answers. Keep this balance and check that the first fact does not reveal the country when editing the catalog.

The historical notes were adapted from [niemela/flags](https://github.com/niemela/flags), licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This adapted catalog is shared under the same license. Individual source URLs are retained in every record and linked from the game. Country names and the initial selection of country codes use [world-countries](https://github.com/mledoze/countries), licensed ODbL 1.0.

The 195 static SVGs in `public/flags/` come primarily from [flag-icons](https://github.com/lipis/flag-icons) under its MIT license, copied to `public/flags/LICENSE`. `af.svg` comes from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_Afghanistan.svg) and is public domain; the older `flag-icons` asset showed the black-red-green republican flag while this catalog describes the white flag used de facto since 2021.

`scripts/build-flag-catalog.mjs` and `scripts/translate-flag-catalog.mjs` document the initial data preparation. The revised pre-answer facts and selected expanded post-answer facts are in `scripts/flag-fact-overrides.en.json`; `scripts/flag-fact-overrides.json` holds their machine-translated RU/UK drafts, and `scripts/flag-fact-editorial.mjs` holds human-reviewed corrections. `scripts/fetch-flag-source.mjs` can refresh the ignored local upstream metadata used for research. Run `node scripts/curate-flag-catalog.mjs` to apply these files to the catalog, then run the catalog tests. Review new or changed facts and all translations before publishing them.
