# Ревью BrainPlay, 20–21 октября 2026

Проверены frontend Next.js 16.4.1, backend NestJS 11 / Prisma 7.10, границы demo/API, профиль, история, рейтинг, сессии и подготовка Google OAuth. Использованы Context7 (Supabase, Prisma, Next.js), документы установленного Next.js и исходники Supabase SDK 2.118. Массовое обновление зависимостей не выполнялось.

## Исправлено

| Приоритет | Проблема                                                                               | Изменение                                                                                                                                    |
| --------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| P1        | Гостевая cookie могла перекрывать зарегистрированную сессию                            | Приоритет bearer/access/refresh; после входа гостевая cookie удаляется                                                                       |
| P1        | Повторяющийся код refresh в игровых сервисах и риск создания гостя при сбое провайдера | Общий Axios session client: один refresh для параллельных запросов; гость создаётся только после 401                                         |
| P1        | Отсутствовала завершённая привязка Google к внутреннему пользователю                   | Backend PKCE, зашифрованная HttpOnly flow cookie, проверка Google identity через getUser, транзакционное объединение и отзыв гостевых сессий |
| P2        | Leaderboard всегда показывал заглушку                                                  | Реальный запрос каталога и top-50 classic режима актуальной версии, состояния загрузки/ошибки/пустого результата                             |
| P2        | Фильтрация истории исключала завершённые партии старых правил                          | В личной истории остаются все поддерживаемые игры и версии; незавершённые/непроверенные/null результаты исключены                            |
| P2        | Никнейм редактировался только локально                                                 | Для действующей серверной сессии используется PATCH /users/me; локальное демо сохраняет прежнее поведение                                    |
| P2        | Очистка незавершённых партий пропускала Time Traveler                                  | Добавлена четвёртая игра                                                                                                                     |
| P2        | При недоступном API профиль мог зациклиться на загрузке авторизации                    | Отключён retryOnMount для общего auth query, локальный профиль не блокируется запросом API                                                   |
| P2        | Refresh мог обновить уже отозванную сессию между чтением и записью                     | Условный update проверяет revokedAt и expiresAt повторно                                                                                     |

Cookie-настройки вынесены в отдельный сервис; срок refresh cookie берётся из REGISTERED_SESSION_DAYS. Приватные ответы используют no-store. При выходе полная перезагрузка уничтожает кеш запросов предыдущего аккаунта. Google доступен в профиле, в том числе до первой партии. Все новые интерактивные тексты есть на EN/UK/RU.

## Проверки

- Frontend: typecheck, lint, production build; 22 unit-теста; 36 Playwright сценариев desktop/mobile.
- Backend: build, typecheck, lint; 42 теста, включая PostgreSQL-миграции в PGlite, cookie/PKCE, HTTP callback, перенос гостя и границы авторизации.
- Браузерные проверки используют подмену API: профиль, серверный никнейм, выход, таблица рейтинга, обработка ошибки Google, игры и локальный профиль при недоступном API.
- PKCE дополнительно проходит через реальный установленный SDK и локальный имитатор Supabase Auth. Это не проверка настоящего входа Google.
- Миграции и пользовательские данные в удалённой Supabase БД при этом ревью не менялись.

## Осталось перед публичным запуском

1. **Внешняя конфигурация Google и проверка настоящего входа.** В Supabase Google provider выключен и не имеет Client ID/Secret. Инструкция: `brain-play-backend/docs/GOOGLE_AUTH_SETUP.md`. Локально флаг GOOGLE_AUTH_ENABLED=false до завершения настройки.
2. **Daily Challenge: единственность результата на сервере.** Сейчас ограничение повторного прохождения опирается на состояние браузера. Требуется бизнес-ключ пользователя/даты/игры и решение, какой результат сохранять при объединении аккаунтов. Не добавлялась миграция с неподтверждённой политикой удаления существующих повторов.
3. **Защита соревновательного рейтинга.** Backend считает результат из ответов, но банк заданий/правильных ответов доступен клиентскому деморежиму. Статус VERIFIED подтверждает серверный расчёт, а не невозможность автоматизированного подбора. Перед соревнованиями/призами нужны отдельная модель выдачи заданий и антибот-защита.
4. **Публикация.** Редакторская проверка контента, политика privacy/consent, реальные AdSense IDs, production origins/cookies, мониторинг, резервное копирование, проверка зависимостей и локализованные metadata остаются отдельными этапами. Preview по-прежнему noindex.

Никнейм остаётся отображаемым именем, не уникальным логином. Идентификация идёт по внутреннему User ID и проверенной внешней идентичности. Демоочки не импортируются в серверный рейтинг. На странице профиля остаются последние 50 записей с пагинацией по 8.
